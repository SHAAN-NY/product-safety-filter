# Product Safety Filter
This was my A-Level Computer Science NEA project. It makes use of the Python SQL3 and Google Translate libraries.

It allows you to store your recipes and instructions, and lets you look up a product and the ingredients that make up that product. It allows you to filter by categories and by specific ingredients. Products with that ingredient and products part of that category will be flagged up when a user scans a barcode including the reason why.

## Usage
Make sure to copy this into your terminal in order to install the Google Translate library dependency.
```bash
pip install googletrans==4.0.0rc1
```

Afterwards, run `psf.py`.
